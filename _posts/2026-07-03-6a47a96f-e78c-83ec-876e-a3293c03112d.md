# BioMatrix｜用统一词表连接生物序列、结构与语言

# 00. 引言：这篇论文想解决什么

BioMatrix 试图解决的是一个生物基础模型（biological foundation model）里的核心断裂：现有模型要么能处理多模态，但只覆盖单一实体；要么能覆盖多种生物实体，但缺少自然语言或显式三维结构建模。论文把这个问题概括成两个轴：一是生物内容如何与自然语言耦合，二是模型能否同时覆盖分子、蛋白及其相互作用。BioMatrix 的目标是把这两条线合并到一个解码器式大模型里。〔引用待核〕

它的核心做法是：把分子序列、分子三维结构、蛋白序列、蛋白三维结构、自然语言全部转成离散标记（token），放进同一个扩展词表里，用同一个 Qwen3 解码器骨干和同一个下一标记预测目标训练。图 1 很关键：它不是“语言模型旁边外挂一个结构编码器”，而是让结构也成为模型可读、可写的标记流。〔引用待核〕

全文主线可以概括为：BioMatrix 不是提出一个全新的分子生成算法或蛋白设计网络，而是把“结构离散化 + 多实体词表扩展 + 大规模连续预训练 + 多任务指令微调”组合成一个统一接口，验证一个问题：生物科学任务是否可以像语言任务一样，统一成“条件标记生成”。

# 01. 背景问题：为什么这件事难

## 1. 生物对象天然不是单一模态

一个小分子至少有三种视角：  
结构式或线性表达，例如简化分子线性输入规范（SMILES）和自引用嵌入字符串（SELFIES）；三维构象；文献中的功能、活性、毒性、合成描述。蛋白也一样：氨基酸序列是一维符号，三维折叠决定功能，自然语言承载功能注释、疾病相关性和实验背景。

真正困难的地方在于，这些视角不是简单冗余关系。序列提供身份，结构决定物理相互作用，语言提供人类任务意图。药物发现、蛋白工程、机制解释还经常涉及多个实体，例如分子—蛋白结合、蛋白—蛋白相互作用。论文明确把这看成统一生物基础模型必须跨过的门槛。〔引用待核〕

【背景知识：原生多模态与适配器式多模态】

适配器式多模态通常是：分子或蛋白结构先由专门编码器变成连续向量，再投影到语言模型。问题是输入和输出不对称：模型能“读”结构特征，但不能自然地“写出”结构，除非再接外部解码器。

原生多模态的思路是：把非文本模态也离散成标记，和文本一起进入同一个下一标记预测框架。BioMatrix 选择的是后者。

## 2. 结构信息很难直接塞进语言模型

三维坐标不是普通文本。坐标有旋转、平移自由度，同一个分子或蛋白换一个坐标系，物理结构不变，但数字完全变了。因此结构标记化必须满足一个基本要求：标记应该描述内在几何，而不是绝对坐标。

BioMatrix 对分子和蛋白用了不同结构标记器：分子用 MolStrucTok 改造版，蛋白用几何向量量化自编码器（GCP-VQVAE）。图 2 展示了两个流程：分子按原子局部球坐标离散化，蛋白按残基骨架几何离散化。〔引用待核〕

# 02. 方法核心：作者到底做了什么

## 1. 统一词表：把所有模态都变成可生成的标记

BioMatrix 扩展 Qwen3 词表，加入五类生物标记：

- 分子一维标记：SMILES、SELFIES；
- 分子三维标记：SELFIES 原子标记与 MolStrucTok 几何码组合；
- 蛋白一维标记：每个氨基酸一个专用残基标记；
- 蛋白三维标记：每个残基一个 GCP-VQVAE 结构码；
- 模态边界标记：标记某段内容是分子、蛋白、结构还是序列。

这个设计解决的是接口问题。传统方法通常为不同任务设计不同输入输出头，BioMatrix 则把任务统一成不同条件下的标记生成：分子描述、文本到分子、蛋白折叠、反向折叠、结构生成、亲和力预测，本质上都是“给定前缀，生成后缀”。〔引用待核〕

## 2. 分子结构标记器：把原子局部几何压成 512 个结构码

分子结构部分基于 MolStrucTok。每个原子不直接记录笛卡尔坐标，而是在一个由分子拓扑确定的局部球坐标系里表示：

\[
g_i=(d_i,\theta_i,\lvert\phi_i\rvert,\operatorname{sign}(\phi_i))
\]

其中 \(d_i\) 是距离，\(\theta_i\) 是极角，\(\phi_i\) 是方位角。由于坐标系由局部拓扑和相对几何定义，这个描述天然不依赖全局旋转和平移。连续几何描述再通过向量量化自编码器（VQ-VAE）映射到 512 个离散码。〔引用待核〕

论文的一个小改动是分支解耦解码器：距离、极角、方位角绝对值、方位角符号分别用独立多层感知机预测。原因很直接：这四个量物理含义和数值尺度不同，强行用一个输出头回归会互相干扰。作者报告这个改动让 QM9-2014 上每个分量的平均均方根偏差约改善 0.1 Å。〔引用待核〕

## 3. 蛋白结构标记器：每个残基一个结构码

蛋白结构使用 GCP-VQVAE。输入是每个残基的主链原子 \(N, C_\alpha, C\)，通过严格三维欧氏群等变（SE(3)-equivariant）的 GCPNet 编码器得到残基表示，再用 4096 大小的码本量化：

\[
\{(x_i^N,x_i^{C_\alpha},x_i^C)\}_{i=1}^{L}
\rightarrow
(z_1,\ldots,z_L),\quad z_i\in\{1,\ldots,4096\}
\]

关键点是残基对齐：长度为 \(L\) 的蛋白序列有 \(L\) 个氨基酸标记，也有 \(L\) 个结构标记。这样折叠就是“氨基酸标记 → 结构标记”，反向折叠就是“结构标记 → 氨基酸标记”。〔引用待核〕

## 4. 训练数据：3044 亿标记的连续预训练

BioMatrix 在 Qwen3 之上连续预训练，数据总量约 3044 亿标记，包含四大类：

- 通用与科学文本；
- 分子多视图数据：SMILES、SELFIES、构象、性质、描述；
- 蛋白多视图数据：序列、结构、功能注释；
- 跨实体数据：分子—蛋白、蛋白—蛋白相互作用，以及嵌入生物医学文本的实体结构表示。

一个重要工程设计是随机组合（stochastic composition）：同一个分子或蛋白的不同字段随机抽样、随机排序，避免模型只记住固定模板。蛋白还用了“三视图实例”：序列单独、结构单独、序列结构联合，让模型同时学习单模态和对齐关系。〔引用待核〕

# 03. 关键机制拆解：最值得理解的技术点

## 1. 真正的新意不是“多模态”，而是“可生成的多模态”

很多生物多模态模型只是能读多模态。例如结构经过编码器进入语言模型，但输出仍然是文本或序列。BioMatrix 的区别在于，结构标记也在同一个输出词表里，因此模型理论上可以直接生成结构标记，再由去标记器还原成三维结构。

这件事的建模意义很大：  
文本到分子、分子到文本、蛋白序列到结构、结构到序列、分子—蛋白亲和力预测，不再需要分别设计架构，而是条件生成模式不同。

## 2. 分子采用“联合标记”，蛋白采用“分解标记”

论文这里有一个很重要的工程取舍。

对分子，作者把 SELFIES 原子标记和 512 个几何码组合成联合标记。例如某个原子既携带“这是 C”这样的化学身份，也携带“局部几何码为 0”这样的结构信息。理论组合数很大，但实际高频组合覆盖 99% 以上出现次数只需要 11294 个联合词表项。〔引用待核〕

对蛋白，如果把 26 个氨基酸标记和 4096 个结构码全组合，会出现约 7 万多个高覆盖联合项，词表膨胀且长尾严重。因此蛋白保持分解表示：氨基酸标记和结构标记分开，但位置一一对应。这个选择体现了很清晰的工程判断：分子长度短、原子类型与局部几何强耦合，联合标记可控；蛋白长度长、残基—结构组合长尾明显，分解表示更稳。

## 3. 结构标记化既是统一入口，也是精度瓶颈

BioMatrix 的统一来自结构离散化，但精度损失也来自结构离散化。分子 3D 标记器只有 512 个几何码，蛋白结构也只保留主链信息，不含侧链精细构象。论文在讨论中明确指出，细粒度三维几何的瓶颈主要在标记化，而不是语言模型本身。〔引用待核〕

这解释了一个实验现象：BioMatrix 在很多分布级结构指标上很强，但分子构象生成的键长分布仍不如专门扩散模型。一个轻量 MMFF 力场优化能明显改善 FCD 和原子稳定性，说明问题集中在几何重建误差，而不是分子整体合理性。

# 04. 实验验证：结果到底说明了什么

## 1. 总体结果：80 个任务中 77 个达到最优或竞争水平

论文评估覆盖 6 大类、80 个任务：分子一维任务、分子三维任务、蛋白一维任务、蛋白三维任务、一维相互作用、三维相互作用。作者报告 BioMatrix 在 77/80 个任务上达到最优或竞争性能。这个结论能支持“统一接口不会显著牺牲专业任务性能”，但不能直接证明“一个单一模型已经完全替代所有专家模型”，因为后续指令微调使用了任务组变体，而不是所有结果都来自同一个单体指令模型。〔引用待核〕

## 2. 分子任务：SMILES 和 SELFIES 各有适配场景

论文最有价值的分子部分，不只是 BioMatrix 分数高，而是系统比较了 SMILES 和 SELFIES。

SELFIES 在无条件生成和属性优化里更强，因为它语法上更容易保证生成有效分子。  
SMILES 在定制化分子生成和反应预测里更强，因为它的表面符号更贴近原子数、键型、官能团等硬约束。

这点很重要：SELFIES 的“有效性保证”不是免费午餐。它把分支、环、键型编码进上下文相关标记里，反而让模型难以直接数原子、数键、识别固定官能团模式。论文在定制化生成任务中观察到 SELFIES 版本几乎崩溃，而 SMILES 版本保持竞争力。这个结果对分子语言模型设计有实际指导意义：不能只凭 valid 高就认定 SELFIES 更适合所有任务。

## 3. 分子三维任务：属性条件构象生成是最大亮点

无条件 3D 分子生成中，BioMatrix 的二维分布指标很好，但原始构象的键长 MMD 较差。经过 MMFF 后处理后，结构质量明显改善。这个结果说明：统一标记生成能产生大体合理的分子与构象，但精细几何还依赖后处理。

更强的证据来自属性条件 3D 结构生成。BioMatrix 在 QM9 的电子结构属性条件生成上大幅降低误差，例如 HOMO、LUMO、HOMO-LUMO gap 相比 NExT-Mol 有约 3–4 倍 MAE 降低。这个实验更能体现统一标记空间的价值：属性数值、结构标记、分子标记都在同一序列里，条件信号更容易直接约束生成。〔引用待核〕

## 4. 蛋白任务：残基对齐设计让折叠与反向折叠变成对偶问题

蛋白一维理解任务中，BioMatrix 在酶编号预测、折叠类型、亚细胞定位、功能注释、知识挖掘等任务上表现强，尤其比通用大模型稳得多。这里的含义是：生物序列知识不能指望通用语言模型自然掌握，仍需要领域数据和专门标记方式。

蛋白三维部分最关键的是折叠和反向折叠。由于每个氨基酸标记对应一个结构标记，模型可以把两者当作两个对齐序列互相翻译。BioMatrix 的折叠 TM-score 接近 DPLM-2 系列，但仍落后 ESMFold；反向折叠的氨基酸恢复率则很高，4B 达到 75.50%，超过 DPLM-2-3B 的 61.67%。这说明它更擅长恢复 native-like 序列，而不是专门为 ESMFold 自洽指标优化的设计序列。〔引用待核〕

## 5. 相互作用任务：跨实体标记流确实有效，但不是 docking 级建模

分子—蛋白和蛋白—蛋白相互作用任务中，BioMatrix 不使用显式几何交叉注意力或口袋专用编码器，只是把两个实体的标记放在同一序列里。论文报告在 BindingDB、PDBBind/CASF、PDBBindv2020 等亲和力预测任务上达到最优或竞争结果。〔引用待核〕

这证明了跨实体预训练和统一词表对亲和力预测有帮助。但需要注意：这不是等价于模型已经能原生做蛋白—配体复合物生成或 docking。论文限制部分明确指出，分子和蛋白结构标记器处于不同几何空间，不能表达配体相对蛋白口袋的位姿。

# 05. 这项工作的真正价值

BioMatrix 的价值主要不是把某个单项指标刷到最高，而是给出一种生物基础模型的系统路线：

1. 生物对象可以被组织成“模态矩阵”：分子/蛋白/相互作用 × 序列/结构/语言；
2. 三维结构可以离散化后进入大语言模型的下一标记预测框架；
3. 多任务生物建模可以部分转化为统一条件生成；
4. 原生多模态在跨模态、跨实体任务上收益最大；
5. 结构标记器将成为下一代生物通用模型的关键基础设施。

这更像是范式变化，而不是单纯“更快”或“更准”。它把过去分散在分子语言模型、蛋白语言模型、结构生成模型、分子—蛋白预测模型里的接口统一起来。

# 06. 局限与需要验证的点

## 1. 分子结构与蛋白结构仍不是同一个三维空间

分子和蛋白分别使用不同结构标记器，码本和参考系不共享。因此 BioMatrix 不能原生表示“配体在蛋白口袋中的相对位姿”。这限制了它在结构基础药物设计中最关键的任务：对接、口袋条件配体生成、复合物构象生成。论文也把统一 3D 标记器列为下一步。〔引用待核〕

## 2. 评估可能存在预训练数据重叠

论文没有做严格实体级过滤。由于 PubChem、UniProt、PDB、BindingDB 等公共数据库高度复用，同一个分子、蛋白或注释可能在预训练、微调、评估中以不同形式出现。这意味着部分强结果可能包含记忆成分。论文对此有说明，但这会影响“泛化能力”的严格判断。〔引用待核〕

## 3. 不是所有结果都来自一个统一指令模型

连续预训练骨干是统一的，但指令微调采用任务组变体。作者解释说，生物任务内部模板高度单一，大任务会压制小任务，所以全任务混合 SFT 不稳定。这个做法合理，但削弱了“一个模型解决所有任务”的强叙事。〔引用待核〕

## 4. 精细三维几何仍受标记器上限约束

分子键长、蛋白 RMSD、侧链构象、复合物界面这些细粒度结构能力并没有完全解决。当前结果更支持“离散结构标记足以表达相当多结构语义”，尚不足以证明它能替代端到端几何模型。

## 5. 通用语言能力可能被领域化侵蚀

论文使用通用文本和 MegaScience 缓解遗忘，但没有系统评估 BioMatrix 相比原始 Qwen3 在通用推理、指令跟随、代码能力上的下降。对于真实 agent 场景，这个缺口需要补测。

# 07. 总结与延伸探讨

总体评价：BioMatrix 是一篇“接口范式”强于“单点算法”的工作，它把分子、蛋白、结构和语言统一到下一标记预测框架里，证明生物基础模型可以从任务专用架构走向模态矩阵式统一建模。

最值得记住的是两点：第一，结构标记化让大语言模型获得了直接生成三维结构的接口；第二，真正的收益主要出现在跨模态和跨实体任务，而不是传统单模态任务。

后续最值得推进的方向是统一复合物级三维标记器。只有能同时编码蛋白口袋、配体、相对位姿、界面相互作用，BioMatrix 这类模型才可能真正进入结构基础药物设计的核心区域。

# 08. 展望

## 1. 这篇论文最脆弱的假设是什么？

最脆弱的假设是：不同模态只要离散成标记，就能被同一个下一标记预测目标充分建模。这个假设在序列、文本、结构语义层面已经有一定证据，但在连续几何、相对位姿、物理能量、分子间相互作用上还不稳。

尤其是蛋白—配体复合物。当前分子结构码和蛋白结构码并不共享一个相对坐标框架，因此模型即使能预测亲和力，也未必真正理解结合位姿。

## 2. 如果有 1 周时间，能做的最小复现实验是什么？

最小复现实验建议验证“结构标记器是不是瓶颈”：

- 选 QM9 子集；
- 用 MolStrucTok 或类似局部几何 VQ 标记器重建构象；
- 比较原始重建、语言模型生成、MMFF 后处理三者的键长/键角/二面角分布；
- 如果 MMFF 能显著修复，而图结构和大体构象不崩，说明误差主要来自量化和几何重建；
- 再把码本从 512 扩到更大，观察键长 MMD 是否下降。

这个实验不需要完整复现 BioMatrix，只验证论文最关键的结构瓶颈判断。

## 3. 如果反对它，我会怎么设计反例？

最强反例应该打在“统一标记空间是否真的理解三维相互作用”上：

构造一组蛋白—配体样本，其中分子和蛋白序列完全相同，只改变配体在口袋中的相对位姿，导致结合模式和亲和力明显不同。若 BioMatrix 不能区分这些样本，就说明它当前的结构标记更像“单体结构描述”，而不是“复合物几何理解”。

另一个反例是长程别构任务：输入同一蛋白不同构象状态，要求模型判断远端突变对配体结合的影响。如果模型只依赖序列和局部结构标记，很可能难以捕捉这种全局构象耦合。
